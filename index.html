iOS OTA Install

Каталог iPhone-приложений

Страница для установки IPA через Apple-ссылку itms-services. Сайт и манифесты можно хранить на GitHub Pages, а IPA-файлы — в GitHub Releases.

Важно: установка сработает только если IPA правильно подписан и iPhone доверяет сертификату/профилю. Сам сайт не обходит ограничения Apple.

HZ Poster

v1.0.0

Демо-карточка приложения. Замени ссылку на IPA, bundle id и версию в manifest.plist.

Bundle ID
com.example.hzposter
Manifest
apps/hz-poster/manifest.plist
Установить на iPhone

Что заменить перед публикацией

  1. В index.html замени USERNAME и REPOSITORY в ссылке установки.
  2. В apps/hz-poster/manifest.plist замени ссылку на .ipa, bundle id, версию и название.
  3. Загрузи сайт в GitHub Pages. IPA лучше положить в GitHub Releases.

Сделано как простой статический сайт: HTML + CSS + manifest.plist.
