Политика конфиденциальности

Как обращаются с данными этот сайт и связанное с ним приложение-автоматизация.

1. Оператор

Персональные данные не обрабатываются ни в каком виде: сайт не использует cookie для рекламы, не ведёт аналитику и не подключает сторонние счётчики и рекламные сети.

Контактный адрес для вопросов по этой политике: soundtrackminus@gmail.com.

2. Доступ к сервисам Google

Приложение-автоматизация (Hermes) работает локально и обращается к Google API от имени владельца аккаунта, который сам выдаёт ему разрешение. Запрашиваются только два набора прав:

  • Google Calendar API — чтение и создание событий календаря, чтобы ставить напоминания.
  • Google Drive API — доступ к файлам, которые владелец аккаунта сам разместил в Google Drive.

Другие сервисы Google — Gmail, контакты, документы, таблицы, задачи — не запрашиваются и не используются. Данные календаря не передаются третьим лицам, не продаются и не используются для обучения моделей.

3. Где хранятся учётные данные

Токен доступа хранится только на личном сервере владельца. Он не попадает в репозитории, не публикуется на этом сайте и не передаётся в другие сервисы. Доступ можно отозвать в любой момент в аккаунте Google: myaccount.google.com/permissions.

4. Что делает этот сайт

Сайт публикует каталог приложений для iOS и ссылки установки. Установка выполняется штатным механизмом iOS itms-services через Safari — это стандартная процедура, а не обход защиты устройства. Счётчики скачиваний не ведутся.

5. Изменения

Политика может обновляться. Актуальная версия всегда находится на этой странице; дата последнего изменения указана внизу.
